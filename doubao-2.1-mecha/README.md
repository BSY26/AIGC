# 豆包大模型 2.1 系列｜作战档案

一个以机甲作战档案为视觉主题的中文单页介绍网站，采用深色 HUD 仪表盘风格展示模型家族、能力标签、案例、定价和生态等内容。

> 本项目为爱好者整理的**非官方**静态展示页面，与字节跳动、豆包或火山引擎不存在官方隶属或背书关系。网页中的模型信息、日期、性能数据、价格及产品名称来自原始页面，**未经过本仓库独立核验**，不应作为官方最新资料；实际信息请以相关厂商公告为准。

## 使用方法

1. 下载本仓库或 ZIP 压缩包并解压。
2. 直接使用现代浏览器打开 `index.html`，即可离线查看网页。
3. 如果需要部署，上传项目根目录的 `index.html` 到任意静态站点托管服务。

无需安装依赖，也不需要执行构建命令、启动后端或配置 API Key。

```text
doubao-2.1-mecha/
```

## GitHub Pages 部署

如果项目在 GitHub 仓库的根目录，可以在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，指定 `main` 分支与 `/(root)` 目录并保存。网页部署地址由 GitHub Pages 生成，是否可用取决于仓库设置与构建状态。

## 技术说明

- HTML5 + 原生 CSS，无 JavaScript、第三方依赖及网络资源请求。
- 中文界面、自适应网格布局、HUD 风格面板及轻度动态视觉效果。
- 若设备未安装楷体系列字体，浏览器会自动使用可用的衬线字体回退。
- 在部分 iPhone 文件预览器中，HTML 可能以源码方式显示；可将文件用 Safari 或其他浏览器打开。
